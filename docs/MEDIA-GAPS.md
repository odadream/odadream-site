## Основные выводы и приоритеты

1. **P1 — образование.** У 14 из 15 программ media пуст. Индивидуальный шаблон программы вообще не выводит programme.media: даже привязанное фото «Вкус и мозг» там не показывается. Общая галерея educationOverview существует отдельно. Нужен общий механизм вывода и затем конкретные привязки.
2. **P1 — состоявшиеся события без медиа.** Сначала закрыть избранные и отдельные страницы найденными материалами, затем искать остальные по источникам.
3. **P1 — Нейросинхронизация.** Одна иллюстрация/экранный материал, нет самостоятельных фото и video. В Golem уже есть подборка с указанием записи NeuroSync Lab 1.mp4.
4. **P2 — видео живых работ.** На многих страницах фотографии есть, а прямого video нет. Видеопревью изображения и hero не считать автоматически плеером на странице работы. Для предметных работ отсутствие видео само по себе не дефект.
5. **P3 — Взлом Мозга / Путешествие к себе.** Совсем без медиа; обе — концепции. Искать эскизы и схемы, не создавать впечатление состоявшегося показа.

## Покрытие по каждой записи

Фото = image с representation=photograph. Прочее = схемы, рендеры, скриншоты, афиши и другие изображения. Видео = kind=video; превью = previewSrc у image (не равнозначно отдельному плееру в MediaFigure). Постер видео не считается самостоятельной фотографией. Отсутствие прямого вложения не означает отсутствие материала в архиве или связанной работе/событии. Заявки, приглашения и предложенные программы не требуют репортажа о состоявшемся показе.
