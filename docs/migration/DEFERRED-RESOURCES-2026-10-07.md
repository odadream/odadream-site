## Что именно означала группа

Техническое правило аудита: файл не вошёл в подготовленный набор ресурсов и не имеет прямой ссылки из Markdown-файлов, зарегистрированных как выбранные текстовые источники V2, но имеет прямую ссылку из других архивных Markdown. Так образовалась группа other-archive-source, затем названная deferred-archive. Проверка не проходила по всей цепочке «медиа-узел → работа/кейс». Поэтому фраза «все 120 относятся к работам вне выбранного набора» была слишком широкой.

## Как читать поэлементный список

Номер D001–D120 фиксирует порядок текущего media-decisions.json. Ссылка на имя файла открывает оригинал из read-only архива; имя Markdown открывает точное место прямого упоминания. Полный исторический URL указан отдельно, поэтому решение можно обсуждать по номеру или адресу.

«Что это» установлено по подписям и описаниям старого сайта; это не новая визуальная атрибуция каждого кадра и не подтверждение всех исторических утверждений. Номера фотографий сохранены: старые подписи часто не объясняют сцену, и сцены не придуманы. Описание PDF основано на архивной медиа-записи, а не на заявлении, что содержание каждой страницы повторно утверждено. Возможность открыть архивный файл не означает право на его повторную публикацию.

В исходном срезе до корректировки курса для всех строк машинное предложение было одинаково: action=retire, approvalStatus=proposed, sourceDisposition=retain-read-only; ожидаемый 404 применим только после будущего переключения и согласования. **Предложения в этом документе не изменяют эти решения и не утверждают 404.** Можно сохранить старый файл по прежнему URL, не показывая его в новом каталоге; перенос редакционного содержания и доступность старого адреса — разные решения.
