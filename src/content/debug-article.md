## STYLE GUIDE

**Text node validation**

Service page for checking basic markdown rendering in a `content` node.

### Scope

- heading hierarchy and paragraph spacing;
- bold/italic/inline-code rendering;
- unordered and ordered list indentation;
- quote block and internal link rendering.

### Control sample

- **Short item** for spacing baseline.
- **Long item** for line-wrap and hanging-indent behavior in list blocks.

1. **Step one**: validate ordered-list numbering.
2. **Step two**: validate wrapped line alignment.

> Service quote block for renderer checks.

Internal link: [[debug]].

## ГАЙД ПО СТИЛЯМ

**Валидация текстовой ноды**

Сервисная страница для проверки базового markdown-рендера в ноде типа `content`.

### Что проверяется

- иерархия заголовков и интервалы между абзацами;
- рендер bold/italic/inline-code;
- отступы и переносы в маркированных и нумерованных списках;
- рендер цитат и внутренних ссылок.

### Контрольный пример

- **Короткий пункт** для базовой проверки интервалов.
- **Длинный пункт** для проверки переноса строк и висячих отступов.

1. **Шаг один**: проверка нумерации списка.
2. **Шаг два**: проверка выравнивания переносов.

> Сервисный блок цитаты для проверки рендера.

Внутренняя ссылка: [[debug]].
