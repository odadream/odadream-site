## PRACTICES

**Applied Neuro-Formats**

Practices is the applied branch of ODA.dream where participants work with attention, body awareness, and state transitions through guided neuroreactive protocols.
Unlike `research`, this section focuses on repeatable session formats that can run in festivals, wellness spaces, and educational settings.

## Format Map

- [[workshops|Workshops]] — entry point: short guided formats with reflection.
- [[neuro-dance|Neuro Dance]] — movement protocol with attention and rhythm feedback.
- [[neurosync|Neurosync]] — group synchronization sessions and collective state work.
- [[gong|Gong Theater]] — sound-led immersive sessions with neuro-visual interpretation.
- [[coaching|Neuro Coaching]] — focused protocols for leaders and teams.

## How to navigate

Start with [[workshops|Workshops]] if you need a first session.
If you want deeper work, continue to [[neurosync|Neurosync]] or [[coaching|Neuro Coaching]].
For performative formats, open [[neuro-dance|Neuro Dance]] and [[gong|Gong Theater]].

## ПРАКТИКИ

**Прикладные нейро-форматы**

`Практики` — прикладная ветка ODA.dream, где участники работают с вниманием, телесной осознанностью и переходами состояний через фасилитируемые нейрореактивные протоколы.
В отличие от `Исследований`, здесь фокус на повторяемых сессионных форматах для фестивалей, wellness-среды и образовательных площадок.

## Карта форматов

- [[workshops|Воркшопы]] — входная точка: короткие управляемые форматы с рефлексией.
- [[neuro-dance|Нейро Танец]] — движение, ритм и работа с фокусом внимания.
- [[neurosync|Нейросинк]] — групповая синхронизация и совместные состояния.
- [[gong|Гонг Театр]] — иммерсивные звуковые сессии с нейровизуальной интерпретацией.
- [[coaching|Нейро Коучинг]] — прикладные протоколы для лидеров и команд.

## Как читать раздел

Для первого знакомства начните с [[workshops|Воркшопов]].
Для более глубокой работы переходите в [[neurosync|Нейросинк]] и [[coaching|Нейро Коучинг]].
Если нужен перформативный формат, смотрите [[neuro-dance|Нейро Танец]] и [[gong|Гонг Театр]].
