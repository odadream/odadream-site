## CULTURAL NEURO CODE

**Ancestry and Cultural Resonance**

Cultural Neuro Code is a research and art line where personal memory, cultural artifacts, and EEG response are studied as one dynamic system.

The project asks a practical question: can culturally meaningful forms become tools of self-regulation when they are translated into neuroreactive interfaces.

## Method

1. **Personal layer:** participant memory materials (family narratives, photos, identity context).
2. **Cultural layer:** curated artifacts (ornaments, songs, stories, landscapes, objects).
3. **Neural layer:** EEG comparison across both sets to detect resonance patterns.
4. **Art layer:** selected artifacts become generative neurofeedback agents.

This creates a bridge from archive to living interaction.

## Output Format

- A relational map of artifacts and resonances.
- A set of interactive media objects driven by biosignal feedback.
- A participatory installation where people can observe and train state transitions through culturally grounded stimuli.

## Why It Matters

The project moves beyond decorative references to heritage.  
It proposes a testable art protocol where culture acts as an embodied interface.

## КУЛЬТУРНЫЙ НЕЙРОКОД

**Наследие и культурный резонанс**

Cultural Neuro Code - исследовательско-художественная линия, в которой личная память, культурные артефакты и ЭЭГ-реакция рассматриваются как единая динамическая система.

Проект отвечает на прикладной вопрос: могут ли культурно значимые формы становиться инструментами саморегуляции, если перевести их в нейрореактивный интерфейс.

## Метод

1. **Личный слой:** материалы памяти участника (семейные истории, фотографии, контекст идентичности).
2. **Культурный слой:** отобранные артефакты (орнаменты, песни, сказки, ландшафты, предметы).
3. **Нейрослой:** сравнение ЭЭГ-отклика на оба набора для выявления резонансных паттернов.
4. **Арт-слой:** выбранные артефакты превращаются в генеративные БОС-агенты.

Так формируется мост от архива к живому взаимодействию.

## Формат результата

- Реляционная карта артефактов и резонансов.
- Набор интерактивных медиа-объектов с биологической обратной связью.
- Партисипаторная инсталляция, где можно наблюдать и тренировать изменения состояния через культурно значимые стимулы.

## Почему это важно

Проект выходит за пределы декоративной работы с наследием.  
Он предлагает проверяемый художественный протокол, в котором культура действует как воплощенный интерфейс.
