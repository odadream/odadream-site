## Mind Grid — event neuro-portrait

Installation-experiment at **BYOB**, Basmanny Dvor, 22 December 2019. A single canvas aggregates **24 neuro-mandalas** — circular diagrams of brain-rhythm intensity (α, β, γ, θ) over time for each participant, plus an Euler diagram of dominant rhythm combinations across the audience.

Shown as **MindGrid**, the early public name for the same line now documented as **[[mindshow|MindShow]]**.

## Mind Grid — нейропортрет события

Инсталляция-эксперимент на **BYOB**, Басманный двор, 22 декабря 2019. Одно полотно объединяет **24 нейромандалы** — круговые диаграммы интенсивности мозговых ритмов (α, β, γ, θ) во времени для каждого участника и диаграмму Эйлера доминирующих сочетаний ритмов в аудитории.

Для публики — под именем **MindGrid**, раннее название той же линии, сейчас **[[mindshow|MindShow]]**.
